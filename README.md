# BlockBreaker

Videojuego de romper bloques desarrollado en Java utilizando el framework libGDX.

## Requisitos

- Java JDK 8 o Java JDK 11. (Probado principalmente en JDK 8)
- Eclipse IDE.

## Ejecución

1. Clonar el repositorio o descargar el proyecto .zip.
2. En Eclipse, seleccionar **File → Import → Gradle → Existing Gradle Project**.
3. Seleccionar la ubicación de la carpeta raíz del proyecto y finalizar la importación.
4. Ejecutar la clase principal del módulo `desktop`.

## Tecnologías utilizadas

- Java JDK
- libGDX.
- Gradle.
- Eclipse IDE.
